# Project rules for every task in this folder

1. Read GYM_DATA.md before writing any content. It is the only source of facts.
2. Never invent facts listed under "NEVER claim or show".
3. Use only photos from /images/site. View them before using them.
4. Do not copy a reference site's logo, photos, text or brand name. Match layout and feel only.
5. Mobile-first, no horizontal scroll, no clipped text, respect prefers-reduced-motion.
6. Show a short plan and wait for approval before changing files.
7. Record anything unverified in TODO-FOR-OWNER.md instead of putting it on the site.
